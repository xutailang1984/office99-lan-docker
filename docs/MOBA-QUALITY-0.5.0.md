# 办公室争霸 0.5.0：质量优化契约

2026-11-10，用户确认按已对齐清单开发、完成验证后更新8080。目标是现有十英雄的镜头、操作与完整比赛质量，沿用办公室主题和现有内容规模。

## 镜头与输入

- 默认自由镜头。鼠标靠近四边/四角平移，回到中央停止。边缘带24 CSS像素；系统菜单可调推屏速度，并保存本机设置。
- 空格按住回看自己，松开恢复自由镜头；Y切换锁定；S停止英雄。镜头平移不改变单位的战争迷雾可见性。
- 镜头边界限制中心位置并覆盖全部可走范围，不要求视口四角全部留在地图内；泉水和边缘英雄可居中，松开空格不会被推回HUD旁。地图外鼠标指向沿原射线裁到可玩边界，预览与指令共用，界内指向保持原样。
- 小地图左键按住临时查看，松开后恢复之前的锁定/临时跟随；原本自由镜头则留在新位置。右键小地图下达移动，中键按地面投影拖动。
- DOM界面与Godot画布共享物理按键/指针状态，命令仍由原生输入事件发出。界面与焦点消息必须先于随后原生按键处理，避免晚到状态吞掉新输入。
- 跨界面松键、离开窗口、切换标签、拖动取消必须释放旧手势。聊天与菜单、连接恢复期间阻断战斗输入；不要用本地动画掩盖连接中断。
- 普通、快捷、松键三种施法保持一致，包含4号侦查。指向技能超距时先走入合法施法范围，真正施放才消耗；移动/停止/新指令取消旧意图。
- 本地点击标记只确认玩家意图，不伪造伤害或命中。帧后标记耗时与主机确认耗时分别记录，均不等同于真人主观手感。
- 后台模拟与网页主线程之间最多一批画面快照在途。加载阻塞后发送最新状态，避免旧帧积压后集中发送触发中继限流；指令结果、心跳和恢复点仍独立可靠传递。

## 对线经济与装备

- 小兵金币归最后一击者：近战21、远程14、炮车/超级兵60。附近队友共享经验，没有通用靠近分金币；每秒2.5基础金币保留。
- 辅助与附近非辅助英雄协作获得额外收入。队友补刀每次8金；有效战斗协作每次10金、间隔至少8秒；公共额度最多30，每分钟补充120。自我治疗、满血治疗、辅助互刷和重复死亡结算不额外发奖。
- 普通助攻奖励统一70金；辅助额外奖励全部使用上述额度。补刀数、累计收入、协作收入可见；敌队即时收入和装备不额外泄漏，结算后公开贡献。
- 现有八件装备分输出、生存、功能三类。普攻和物理技能由护甲减免，法师/辅助技能由魔抗减免，惩戒为真实伤害；防护衣对应护甲，保温杯对应魔抗。
- 商店六格提示从规则读取，分类切换保持弹窗外框尺寸。技能提示显示冷却、法力、射程与范围，死亡摘要展示最近伤害与关键控制。

## 地图与整局

- 保持300项目单位地图，新增史诗目标院墙、宽入口与侧向退出通道。地面引导沿真实寻路结果生成，不穿墙误导；三路与双方营地路径都需检查。
- 英雄/兵线使用有界空间桶软分离，不重新生成全局动态寻路。泉水保护、回城和施法等状态避免被分离推移；窄口、交汇和边缘均应实测。
- 机器人补刀、回城更新装备、插眼、召唤师技能、守塔、争夺目标和集结推进使用现有规则；隐蔽敌人不能作为决策输入。
- 延续准备、加载、对战、主机交接、恢复、胜负、重开和退出。新增断线自动重试，恢复前不放开输入；对局确已结束则退回大厅，不遗留假战场。

## 验证边界

规则、真实输入、画面表现、完整比赛、网络/性能分别留证。实际双浏览器加机器人不等于十台公司电脑；加速比赛不替代实时性能采样。最终结果以配套验收记录与 `.work/moba-quality-050/` 的候选指纹、报告为准。
