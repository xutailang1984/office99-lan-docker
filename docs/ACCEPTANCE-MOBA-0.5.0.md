# 办公室争霸 0.5.0 验收

本轮围绕现有十英雄优化镜头、操作、对线经济和完整对局，不增加英雄数量。PVE 继续保留为 0.18.0。

## 建议体验顺序

| 项目 | 怎么试 | 预期 |
| --- | --- | --- |
| 自由镜头 | 鼠标移到四边和四角，再回中间；跨过技能栏、聊天和小地图 | 对应方向推屏，回中停止；不会失去镜头控制 |
| 镜头快捷键 | 按住空格、松开；按 Y；小地图左键拖看；中键拖动 | 空格暂时看自己，Y 切换锁定；小地图松手恢复原镜头模式；菜单可调速度 |
| 指令与施法 | 右键移动/攻击、A＋左键、S 停止；学技能后立即按 QWER；试三种施法与 4 号侦查 | 不漏键、不持续误走；超距指向技能先走近，S 或新指令取消；点击及时给出指令标记 |
| 补刀与辅助 | 自己补掉小兵，再让队友补掉；辅助陪队友打线、治疗受伤队友 | 小兵金币只给最后一击；附近仍有经验与基础金币；辅助另有受限协作收入 |
| 地图与交战 | 走三路、野区和首领区；穿过窄口与兵线；比较外/内/高地/门塔 | 路口可辨，地面指引不穿墙；单位不会永远挤成一团；推镜头不会揭开迷雾 |
| 商店与信息 | 切换输出/生存/功能分类；查看技能、Tab 战况、死亡摘要 | 弹窗外框稳定，六格装备清晰；能看懂补刀、收入和主要死因 |
| 联机恢复 | 在测试局刷新；房主离开，队友继续 | 恢复时有提示并暂时阻断操作，恢复后可继续；结束的房间应回大厅 |
| 完整一局 | 选人、准备、出兵、推塔、破基地、结算、重开、退出 | 双方胜负相反，十人贡献齐全，重开回选人且成长重置 |

**按键提醒：空格控制镜头，S 才是停止英雄。** 未补刀时金币仍随基础收入增长，不能仅凭“金币增加”判断是否分到了小兵金币。

## 本轮修复说明

- 修复 UI 焦点消息晚到后吞掉下一次空格/技能按键；统一网页 UI 和游戏画布的按键、鼠标状态。
- 修复退出场景时旧画面仍读取无效输入状态的报错；旧画面只能收到阻断输入的安全状态，不能干扰新一局。
- 修复超距追踪施法被控制打断后仍沿旧路径移动。
- 修复首次画面加载阻塞主线程时，后台旧快照积压、集中发送触发中继限流。快照批次现在有处理确认，可靠指令结果和恢复点独立传递。
- 地图增加首领区围合与出口，路线依据实际寻路生成；兵线/英雄有轻量分离。
- 严格补刀、辅助收入额度、物理/魔法防御、战况与死亡摘要一起调整。

## 验证边界

- 双真实浏览器加八机器人，是本机渲染与输入联机验证；十连接协议压力不是十台同事电脑的实际网络测试。
- 完整对局使用正式数值与胜负条件、机器人决策，模拟时钟加速十倍；它用于验证比赛循环，不能替代实时性能采样。
- 技能表现专项预置等级、目标与资源，用于检查四十项技能的真实画面、命中指向与特效回收，不代表自然成长和平衡已获用户认可。
- 本地指令标记的帧后耗时不等于真实命中耗时，也不等于屏幕实际发光延迟。手感、美术与乐趣仍由真人验收。
- 采用成熟 PC MOBA 的操作范式；没有复制 LOL 的官方地图坐标、资源或全部赛季规则。
